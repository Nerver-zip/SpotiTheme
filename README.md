# SpotiTheme

Standalone theme-only Android Xposed module for pinned Spotify 9.1.86.2432.

## Attribution

Derived from [LeNerd46/SpotifyPlus](https://github.com/LeNerd46/SpotifyPlus), licensed under MIT. The original copyright and license are retained in LICENSE. Vector, DexKit research and the Catppuccin community informed the original theme work.

Port in progress: this core scaffold is not yet a functioning injected theme module. Static reflection, hooks, standalone UI and the installer are subsequent bundles. Startup below 50 ms is a measured acceptance target, not an established result. Known alternate-renderer limitations from the source project remain to be assessed.
